# 已知限制及未完成項目

## 已實作但尚未以真實帳戶驗證
- **真實 Google Sheets 整合**：程式碼已完成（建立、保護、分享、讀取公式＋數值、交叉核對），並以模擬 Google API 的測試驗證請求及解析邏輯（`test/g-google-adapter.test.js`）。開發環境沒有 Google 憑證，**尚未對真實 Google 帳戶執行**。部署前必須執行 `npm run google:smoke` 及以學生帳戶人手確認（規格 §14 要求最少兩隊）。
- **Google Sign-in**：以 Google 官方 `verifyIdToken` 核實；同樣需要部署時以真實 Client ID 測試。
- **保護範圍**：Google Sheets 的保護可阻止學生修改原始數據，但擁有者／編輯者在某些情況（例如複製工作表）仍可繞過；系統以提交前的完整性比對作最後防線。

## 待老師提供
- **廣東話配音自然度**：已附帶的 30 句由本機開源粵語模型產生（語音辨識回譯平均相似度 0.76，可聽懂、確實是粵語），但屬帶機械感的合成語音，各角色以同一聲音加音高／語速處理區分，不及真人。建議正式課堂前由老師試聽，把不自然的句子改為真人錄音，或改用 Azure zh-HK 神經語音（需要金鑰，本環境未能測試）。
- 開發者無法親耳試聽；音質判斷只基於語音辨識回譯及聲學檢查。
- 瀏覽器端的聲音在自動測試中以「實際載入的音檔」及「音效紀錄」驗證；無法以耳朵確認課室喇叭實際音量，請上課前試一次。
- **角色圖片**：現時使用內建原創 SVG；你提供插圖後可在控制台上載（規格見 CHARACTER_ART.md）。
- `TIMER_WARNING` 的一句「仲有一分鐘！大家檢查清楚先好提交！」是按規格 §9.2「站長短廣播」補寫的，請老師確認。
- **未教授函數的替代題目**：規格要求「教師批准的已教版本」；目前沒有預先審核的替代題目，系統會阻止開始該關並容許老師「略過」（須寫理由）。

## 雲端部署
- **尚未提供實際網址**：開發環境沒有你的 GitHub／Render 帳戶權限，不能代你建立雲端服務。程式已按 Render Blueprint 準備好，並以 PostgreSQL 在正式（production）設定下測試（重啟、強制終止後資料保留；多瀏覽器流程）。部署步驟見 DEPLOY_CLOUD.md。
- **費用**：全免費（Render Free 網站＋ Neon Free 資料庫）。Render Free 閒置 15 分鐘會休眠，休眠後第一次開啟要等約 30–60 秒，請上課前 5 分鐘先開啟網址；比賽進行中系統會自動保持喚醒。Free 方案 CPU 較慢，預檢可能需要數秒。
- **Neon 連線**：已以本機 PostgreSQL 模擬 Neon 休眠（中斷所有連線、拒絕連線後恢復）測試，寫入會自動重試；尚未連接真實 Neon 帳戶測試。
- 雲端版本預設**不包含**本機粵語 TTS 引擎（避免記憶體不足）：已附帶全部 30 句配音；老師可錄音／上載替換。如需在雲端「重新合成」，可用 Dockerfile 的 `INSTALL_TTS=true` 並選較大記憶體方案（需付費）。

## 設計上的取捨
- **單一伺服器實例**：狀態存於記憶體，並即時寫入 PostgreSQL（雲端）或 `state.json`（本機）。一班 20 人的負載很小（模擬 548 次提交，平均 7 ms）；如需多實例或高可用，需要改用資料庫（例如 Firestore／PostgreSQL）並使用跨實例鎖。
- **公式引擎**支援本集所需及常用函數（SUM、AVERAGE、COUNT、COUNTA、MAX、MIN、IF、AND、OR、NOT、COUNTIF、SUMIF、LEFT、MID、RIGHT、LEN、CONCATENATE、ROUND、INT、ABS、LARGE、SMALL 等）。學生使用其他函數時不會被誤判為概念錯誤，而是標示「需要老師覆核」並不扣分。
- **等價公式**：沒有指定函數的題目（例如 L2 H2「使用合適函數」）接受任何在本隊及隱藏數據都正確、且非寫死的公式。題目明確指定函數或運算（SUM、COUNT、COUNTIF、SUMIF、`$H$1`、`">="&H1`、LEFT/MID/RIGHT、`&`）時，必須同時通過結構檢查。
- **L3 隱藏測試**把年齡界線改為 65，以找出在條件中寫死 60（而不引用 H1）的公式。
- **全部空白的提交**不扣錯誤提交分（避免誤按），但仍顯示提示。
- **Demo 模擬工作表**提供選取、公式列、複製貼上（相對參照位移）、向下填充；不支援拖曳填充柄、插入列等完整試算表功能，只用於試玩。
