# 老師使用指南（45 分鐘課堂）

## 開啟網站
學校電腦用 Chrome／Edge 開啟學校的遊戲網址（例如 `https://taiyau-station.onrender.com`），不需要安裝任何軟件。比賽資料存放在雲端，課後關掉電腦不會遺失；下次開啟同一網址即可繼續或匯出成績。

> 網站由免費的 cron-job.org 每 10 分鐘自動喚醒（設定見 [DEPLOY_CLOUD.md](DEPLOY_CLOUD.md) 步驟 5），24 小時都可立即開啟。
> 如開啟時見到 Render 的「waking up」畫面，表示定時喚醒停了：等約 1 分鐘即可使用，課後登入 cron-job.org 檢查並重新啟用。
> 建議上課前先開啟一次網址，確認已載入才請學生登入。

## 聲音
- **劇情聲音**（配音、背景音樂）：只在投影畫面播放；在「D. 即時控制」可暫停、重播、跳過、靜音及調音量。
- **學生遊戲音效**：在學生自己的裝置播放（答對、答錯、完成任務、新關卡、Bonus、提示），只播放該隊相關的音效；學生可自行靜音及調音量。如課室需要安靜，可請學生按頂部 🔇。

## 課前（約 15 分鐘，可前一天完成）
1. 以老師帳戶登入 → **A. 設定**：比賽標題、班別代號、隊伍數目（預設 6；20 人可用 4+4+3+3+3+3）、每關時間、**勾選已教授的技能**、是否開啟 Bonus。
   - 某關涉及未勾選技能時，系統不會開始該關；你可以補勾、或在 D 頁「略過」該關（須寫理由）。系統不會用未審核的題目替換。
2. **C. 數據預檢**：按「生成數據」。系統為每隊生成不同數據，並對每隊每題自動測試參考公式、等價公式、常見錯誤公式及隱藏測試（每隊 73 項）。
   - 「查看」可預覽該隊的數據、參考公式及預期值（**只供老師，請勿投影**）。
   - 不滿意可「重新生成」；按「以相同 Seed 重現」會得到完全相同的數據。
3. 全部通過後按 **「批准並鎖定」**。之後數據不能無聲地改變。
   - 正式模式：再按「建立／重試 Google Sheets 並分享」。若某隊顯示錯誤，畫面會寫出原因。
4. 按 **「開放大堂（Lobby）」**。
5. 在投影電腦開啟 **B. 隊伍 → 開啟投影畫面**，按一次「🔊 啟用投影聲音」（只需一次；之後劇情自動播放）。劇情聲音只會由這個投影畫面播放，老師控制台及學生裝置不會播放劇情。
6. 「配音資產」：確認需要的對白音檔已試聽並批准（沒有音檔也可以照常比賽，只顯示字幕）。

## 課堂流程
| 時間 | 老師操作 |
|-|-|
| 00:00–04:00 | 投影顯示比賽代碼；學生登入 → 輸入代碼 → 選隊。在 **B. 隊伍** 檢查人數，必要時「轉至…」（須寫原因）。可設定隊長及每關角色（系統已自動輪換 Driver）。 |
| 04:00 | **D. 即時控制 →「▶ 開始遊戲」**（投影畫面自動播放開場劇情及背景音樂）→「開始」第 1 關 |
| 每關 | 學生在工作表作答，按「檢查／提交」。你可在 **E. 即時診斷** 看各隊進度、常見錯誤、同步問題。剩 60 秒系統自動提醒；時間到自動截止並播放結束對白。 |
| 需要時 | 「暫停」（暫停期間不計時）、「+1 分／+2 分」延長、「結束」提前截止、排行榜「隱藏／凍結」、緊急靜音 |
| 40:00 | 第 5 關截止後系統自動播放最終揭曉（LUNCH）及第二集預告 → 按「顯示結果」 |
| 40:00–45:00 | **F. 結果 → 賽後回顧**：系統列出全班最常見的 2–3 個錯誤（固定格式：錯誤公式／錯在甚麼地方／Keyword／可得分公式／Question Clue／應用），不顯示哪隊犯錯。 |

## 分數規則（每隊相同）
- 每關基礎分上限 500 = 500 × 已取得評分點 ÷ 該關評分點。
- 所有必答題首次提交即正確 +20；完成全關速度獎勵 0–30。
- 提示：第 1 級 −10，第 2 級再 −20。錯誤提交每次 −5（每關最多 −20）；同步失敗、資料完整性錯誤、需要覆核及空白提交不扣分；同一工作表內容重複提交不重複計分或扣分。
- 連續三關全部完成 +20（一次）；Bonus 加題 +50（如開啟）。單關最低 0 分。
- 排名：總分 → 已完成關數 → 少用提示 → 較早取得有效正確提交。

## 處理特殊情況
- **老師控制台顯示「伺服器曾中斷約 N 秒，系統已自動暫停並補回中斷期間的作答時間」**：雲端伺服器曾重新啟動（約 1 分鐘）。關卡已自動暫停，中斷期間不計時；已顯示「已核實」的答案及分數全部保留。請學生確認畫面已重新連線（如有需要按重新整理），然後按「繼續」。
- **學生畫面顯示「伺服器重新連線中，正在自動重試提交…」**：請學生等候，不要關閉頁面；系統會自動重試約 3 分鐘，不會重複計分。如之後顯示「比賽暫停中」，待老師按「繼續」後再按一次提交。
- **課堂中不要更新程式碼**（推送到 GitHub 會令網站自動重新部署及暫停）。
- **學生看到「資料已被修改，請通知老師」**：該隊改動了原始數據。可在 E 頁查看是哪些儲存格；請學生按 Ctrl+Z 還原或由老師修正，再提交。不會扣分。
- **「同步失敗（不會扣分）」**：網絡或 Google API 問題，請學生再按一次。連續失敗系統會自動暫停計時。
- **「需要老師覆核」**：學生用了系統未支援的函數，或 Google 計算結果與伺服器引擎不一致。在 E 頁查看快照，必要時在 F 頁「手動調分」（須寫原因，系統記錄改前／改後分數、操作者及時間）。
- **題目本身有問題**：F 頁「取消題目」，所有隊伍同步等值處理。
- 所有管理操作都記錄於「審計紀錄」。

## 賽後
F 頁「匯出 CSV」（或匯出到 Google Sheets）。之後可「封存」；如需刪除資料，先取消／封存，再按「刪除比賽資料」。
