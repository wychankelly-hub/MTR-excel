# 老師使用指南（45 分鐘課堂）

## 開啟網站
學校電腦用 Chrome／Edge 開啟學校的遊戲網址（例如 `https://taiyau-station.onrender.com`），不需要安裝任何軟件。比賽資料存放在雲端，課後關掉電腦不會遺失；下次開啟同一網址即可繼續、查看歷史比賽或匯出成績。

> 網站在無人使用時會休眠，**上課前約 2 分鐘先開啟一次網址**。如見到 Render 的「waking up」畫面，等約 1 分鐘即可。課堂期間系統會自動保持喚醒；下課後自動停止（不需要 24 小時喚醒）。下課後請關閉投影畫面分頁。

## 學生作答介面：內置工作表
學生在遊戲網站內的工作表作答，**不需要 Google Sheets**：
- 公式列、`$` 絕對／相對參照（F4 切換）、複製貼上及「向下填充」（公式會按相對參照自動調整）、方向鍵、Enter／Tab、Ctrl+Z／Ctrl+Y、函數提示。
- 原始數據及非作答格受保護（灰色），學生不能修改；未開放的題目不能輸入。
- **每隊只看到自己的工作表**：伺服器按登入帳戶及老師分隊檢查，更改網址或參數都不能看到或修改其他隊伍。
- 隊友的修改約一秒內同步；兩人同時改同一格時，後到的一方會看到「衝突」提示並載入最新內容（不會無聲覆蓋）。每格修改確認後才顯示「已儲存」，重新整理或伺服器重新啟動都不會遺失。
- 舊比賽如使用 Google Sheets，仍然可以照常使用（「舊模式」）；新比賽預設使用內置工作表。

## 聲音
- **劇情聲音**（廣東話配音、背景音樂）：只在投影畫面播放；在「D. 即時控制」可暫停、重播、跳過、靜音及調音量。
- **學生遊戲音效**：在學生自己的裝置播放，只播放該隊相關的音效；學生可自行靜音。

## 課前（約 15 分鐘，可前一天完成）
1. 以老師帳戶登入 → **A. 設定**（頂部選單「＋ 新增比賽」）：
   - **劇集**：Episode 1《新人報到》或 Episode 2《疑犯火箭仔》（預設最新一集）。
   - 比賽標題、**班別代號**、隊伍數目（預設 6；20–30 人可用 6 隊）、每關時間、**勾選已教授的技能**。
   - **分隊方式**：「老師分隊」（建議）——學生輸入代碼後先進入等候名單，由你分隊；或「學生自選一次」（之後只有老師可以轉隊）。
   - 可選：「學生必須以 Google 帳戶登入」、學生名單（學校網域或電郵），防止其他班或校外人士加入。
   - 可選：「逐題開放」（開始關卡時只開放第一題）、「全對的題目自動鎖定」（預設開啟）。
2. **C. 數據預檢**：按「生成數據」。系統為每隊生成不同數據，並對每隊每題自動測試參考公式、等價公式、常見錯誤及隱藏測試（第一集每隊 73 項、第二集每隊 74 項）。「查看」可預覽該隊的數據、參考公式及預期值（**只供老師，請勿投影**）。
3. 全部通過後按 **「批准並鎖定」**（系統同時為每隊建立內置工作表）。
4. 按 **「開放大堂（Lobby）」**。
5. 在投影電腦開啟 **B. 隊伍 → 開啟投影畫面**，按一次「🔊 啟用投影聲音」。
6. 「配音資產」：試聽並批准需要的對白（第二集 30 句已附帶本機合成的廣東話配音；可錄音或上載替換）。

### 多班別
- 每一班建立一場比賽：各有自己的比賽代碼、名單、工作表、分數、排行榜及計時，互不影響（不同班可以用相同的隊伍名稱）。
- 學生輸入代碼後會先看到「班別、比賽名稱」確認畫面，避免入錯班。如有學生入錯班，在 B 頁「移除」（須寫原因）。
- 頂部選單可隨時切換比賽，查看以前的比賽及成績。B 頁「複製名單」可把另一場比賽的分隊名單複製過來。

## 課堂流程
| 時間 | 老師操作 |
|-|-|
| 00:00–04:00 | 投影顯示比賽代碼；學生登入 → 輸入代碼 → 確認班別。**B. 隊伍**：在「等候分隊」逐一分隊或按「⚖ 自動平均分隊」；需要時「轉至…」（須寫原因）。 |
| 04:00 | **D. 即時控制 →「▶ 開始遊戲」**（投影播放開場劇情）→「開始」第 1 關 |
| 每關 | 學生在工作表作答，按「檢查／提交」。**E. 即時診斷** 看各隊進度及常見錯誤；**G. 題目及工作表** 看任何一隊的題目及即時工作表。剩 60 秒自動提醒；時間到自動截止並播放結束對白。 |
| 需要時 | 「暫停」、「+1 分／+2 分」、「結束」、排行榜「隱藏／凍結」、緊急靜音 |
| 約 40:00 | 第 5 關截止後自動播放最終揭曉（第一集：LUNCH；第二集：真相——火箭仔清白）→ 按「顯示結果」 |
| 40:00–45:00 | **F. 結果 → 賽後回顧**：全班最常見的 2–3 個錯誤（不顯示哪隊犯錯）。 |

## G. 題目及工作表（老師專用）
- 選擇**關卡、題目、隊伍**：左邊顯示學生看到的題目（使用該隊數據），下面的「老師專用」部分顯示參考公式、評分點及常見錯誤（**請勿投影**）。
- 右邊是該隊的**即時工作表**（唯讀），學生輸入時即時更新。
- 狀態表顯示每隊每題：未開放／進行中／已完成／已截止／已重開。
- **逐題控制**：「▶ 開放」某題（其餘未開放的題目學生不能輸入或提交）、「🔒 鎖定」某題（例如提早收卷）。時間到或全對後題目會自動鎖定；未開放的題目內容不會傳送給學生。
- **重開（Reopen）**：選好題目後按「↺ 重開…」，選擇隊伍（可選全部隊伍）：
  - **練習模式**（預設）：學生在另一份練習工作表重做（預設由該隊目前的作答開始；可勾選「由起始內容重新開始」），提交只顯示對錯，**不計分、不改排行榜**，原來的作答及分數完整保留；不影響正在進行的計時。
  - **補做模式**：在原工作表補做，只取得基礎分（沒有速度獎勵，錯誤不扣分）；用於學生缺席或技術問題。
  - 重開會一直保留（重新整理或伺服器重新啟動後仍在），完成後在該重開項目旁按「結束」。

## Episode 2《疑犯火箭仔》
肥站長的最佳站長獎座午飯時間在辦公室消失，門禁紀錄顯示火箭仔的員工證開過門。學生用數據調查：
| 關卡 | 內容 | 函數 |
|-|-|-|
| L1 門禁紀錄 | 拆開「地點@時間#員工證」紀錄，計算目標員工證出現次數 | FIND、MID、RIGHT、LEN、COUNTIF |
| L2 員工名冊 | 查出每張證的主人及當值時段；訪客顯示 VISITOR；反向查找 | XLOOKUP（含「找不到時的值」）、$ |
| L3 現金箱對數 | 金額四捨五入至一毫、計算現金袋數、總額 | ROUND、INT、SUM |
| L4 不在場證明 | 計算各人與辦公室的距離並排名，找出最接近者 | SQRT、^、RANK、XLOOKUP |
| L5 隨機抽查 | 隨機數、抽查次序、隨機儲物櫃號碼 | RAND、RANK、INT |

- 每隊數據不同（地點及號碼長度、名冊、金額、位置），另有隱藏測試數據，寫死數值或參照錯誤的公式會被找出。
- L5 的 RAND 題目以多組可重現的隨機數重算（例如 400 次），確認結果永遠在正確範圍、而且 1 及 H1 都會出現。
- 最終揭曉：八仔借了火箭仔的證，把獎座拿到失物認領處抹乾淨——火箭仔是清白的。

## 分數規則（每隊相同）
- 每關基礎分上限 500 = 500 × 已取得評分點 ÷ 該關評分點。
- 所有必答題首次提交即正確 +20；完成全關速度獎勵 0–30。
- 提示：第 1 級 −10，第 2 級再 −20。錯誤提交每次 −5（每關最多 −20）；同步失敗、資料完整性錯誤、需要覆核及空白提交不扣分；同一內容重複提交不重複計分或扣分。
- 連續三關全部完成 +20（一次）；Bonus 加題 +50（第一集，如開啟）。單關最低 0 分。
- 練習模式的提交一律不計分。

## 處理特殊情況
- **「伺服器曾中斷約 N 秒，系統已自動暫停並補回時間」**：雲端伺服器曾重新啟動。已儲存的工作表內容、已核實的答案及分數全部保留。請學生確認畫面已重新連線，然後按「繼續」。
- **學生畫面顯示「未儲存」或「重新連線中」**：系統會自動重試；請學生不要關閉頁面。重新連線後未確認的修改會再次送出。
- **學生看到「衝突」**：隊友剛改了同一格，畫面已載入最新內容；如有需要再輸入一次。
- **課堂中不要更新程式碼**（推送到 GitHub 會令網站自動重新部署及暫停）。
- **「需要老師覆核」**：學生用了系統未支援的函數。在 E 頁查看，必要時在 F 頁「手動調分」（須寫原因，全部記錄於審計紀錄）。
- **題目本身有問題**：F 頁「取消題目」，所有隊伍同步等值處理。

## 賽後
F 頁「匯出 CSV」。之後可「封存」；如需刪除資料，先取消／封存，再按「刪除比賽資料」。
