# 廣東話配音、背景音樂及音效

## 開箱即用
- 雲端部署時，附帶配音隨網站一併部署；老師在控制台錄音／上載的配音存放在雲端資料庫，重新部署亦不會消失。
- `public/audio/` 已附帶全部 **30 句廣東話配音**（mp3，共約 0.8 MB），由本機開源粵語語音模型產生，**不需要任何雲端金鑰或網絡**。
- 模型：sherpa-onnx 的 **Cantonese VITS**（`vits-cantonese-hf-xiaomaiiwn`）。它以**粵語音素及六聲調**發音（詞典例子：咗 ʦɔː˧˥、唔 m̩˨˩、啲 tiː˥），不是普通話模型。
- 角色聲線：同一模型，以不同語速、音高及共振峰處理（ffmpeg rubberband）區分：

| 角色 | 設定 |
|-|-|
| 陳定 | 語速 0.95、音高 ×0.86（平穩、略低沉） |
| 肥站長 | 語速 1.0、音高 ×0.76、加低音（低沉、誇張） |
| 火箭仔 | 語速 1.15、音高 ×0.93（快、自信） |
| 八仔 | 語速 1.0、音高 ×1.12（清脆、活潑） |
| 喂喂叔 | 語速 1.05、音高 ×0.74 |
| 乘客甲 | 原聲 |

- 英文詞（IF、OR、AND、LUNCH）以英文字母逐個讀出；罕用字「𠱸」以同音字「臣」合成；詞典中部分繁體字沒有讀音時，自動改用讀音相同的簡體字作合成輸入。**字幕永遠顯示原句。**

### 客觀檢查（語音辨識回譯）
我們用另一個開源**粵語**語音辨識模型（sherpa-onnx Paraformer 三語模型）把 30 句配音轉回文字，與劇本比較：
- 平均字元相似度 **0.76**（未經聲線處理的原聲約 0.70–0.76，即聲線處理沒有令清晰度下降）。
- 辨識結果大量出現粵語專用字（啲、咗、嘅、唔、冇、搵、諗、哋、喺），證明讀音是粵語。
- 最低的幾句（例如「用數據搵答案」「LUNCH」逐字母讀出）較難聽清楚，建議由老師錄音取代。
重現方法：`python3 scripts/verify-tts-asr.py <ASR 模型資料夾>`。

> ⚠️ 本機模型屬「清楚但帶機械感」的合成語音，自然度不及真人或商業神經語音。正式課堂如追求最自然效果，建議：
> 1. 老師／同學在控制台「配音資產」逐句按「🎙 錄音」；或
> 2. 使用 Azure zh-HK 神經語音：`AZURE_SPEECH_KEY=… AZURE_SPEECH_REGION=eastasia npm run tts:generate -- --provider azure --force`

## 兩套獨立的聲音系統

### A. 劇情聲音 —— 只由投影畫面播放（全班一起看）
- 包括：角色廣東話配音、劇情場景、背景音樂、每關開車鐘聲、最後 10 秒倒數嗶聲、完成一關鐘聲、最終揭曉。
- **只由一個「指定投影畫面」播放**；老師控制台只同步顯示字幕，**永不發聲**；學生裝置**永不播放**劇情或背景音樂。
- 如開了多於一個投影視窗：第一個按「啟用投影聲音」的視窗負責播放，其他視窗只顯示字幕；需要時可在另一個視窗按「改由這個畫面播放」接手；指定視窗關閉超過 45 秒，下一個已啟用聲音的視窗自動接手。
- 一次性啟用：在投影電腦開啟投影畫面 → 按一次「🔊 啟用投影聲音」（瀏覽器規定）。之後老師在控制台按「開始遊戲」、開始每一關等，劇情都會**自動**在投影畫面播放，不需要再按播放。
- 老師在控制台「D. 即時控制」可遙控：暫停、繼續、重播、跳過、靜音、緊急靜音、音量、背景音樂開關，並可重播任何已解鎖的劇情。投影畫面底部亦有同樣按鈕。
- 字幕在音檔真正開始播放時才出現；角色嘴巴按音量開合；配音時背景音樂自動降低。

### B. 遊戲音效 —— 在每位學生自己的裝置播放
| 事件 | 誰會聽到 | 聲音 |
|-|-|-|
| 本隊提交答對 | 本隊所有隊員 | 清脆雙音 |
| 本隊提交答錯 | 本隊所有隊員 | 柔和低音（不刺耳） |
| 本隊完成全關（任務完成） | 本隊所有隊員 | 上行成就和弦 |
| 新一關解鎖 | 全班學生 | 上揚＋鐘聲 |
| Bonus 加題答對 | 本隊所有隊員 | 閃亮獎勵音 |
| 本隊使用提示 | 本隊所有隊員 | 輕柔提示音 |
- 其他隊伍的答對／答錯**不會**在你的裝置播放。
- 音量偏低並經壓縮限制，適合課室；學生可按頂部 🔊／🔇 靜音，並用滑桿調校音量（只影響自己的裝置，下次開啟仍記住）。
- 一次性啟用：學生登入、輸入比賽代碼時的第一次點擊已自動啟用；未啟用時頂部會顯示「按一下畫面啟用音效」。
- 重新整理或網絡重新連線**不會重播**已播放的音效。
- 學生音效與投影劇情聲音完全獨立：老師在控制台靜音劇情，不影響學生音效；學生靜音亦不影響投影。

## 原創鐵路風格音效及配樂（Web Audio 即時合成）
| 時機 | 音效 |
|-|-|
| 每關開始 | 月台三音鐘聲 + 關門嗶嗶聲（列車開出） |
| 隊伍答對一題 | 到站「叮咚」（投影端；同時顯示隊名，不顯示答案） |
| 隊伍完成一關／首隊完成 | 上行四音鐘聲 |
| 學生答錯（只在該隊裝置，預設靜音） | 柔和低音提示 |
| 剩一分鐘 | 提醒鐘聲 + 肥站長廣播 |
| 最後 10 秒 | 每秒一下短嗶聲（關門提示音風格） |
| 時間到 | 雙音提示 |
| 最終揭曉 | 和弦 |
| 背景音樂 | 柔和和弦 + 低音 + 「咔嚓咔嚓」路軌節奏，配音時自動降低 |
全部為原創合成，不使用任何港鐵或其他受版權保護的聲音。

## 重新產生／替換配音
```bash
npm run tts:setup
```
```bash
npm run tts:generate -- --provider local --force
```
- `tts:setup` 下載本機粵語模型（約 110 MB，存於 `models/`）。之後伺服器啟動時會**自動補齊**缺少的配音，控制台每句亦有「🗣 重新合成」按鈕。
- 修改角色聲線：`server/tts/local-tts.js` 的 `VOICE_PROFILES`。
- 控制台「配音資產」可試聽、批准、退回（退回後該句只顯示字幕）、錄音或上載。設定 `AUDIO_REQUIRE_APPROVAL=true` 則只播放老師已批准的音檔。

## 後備
- 音檔缺失／載入失敗／瀏覽器阻止播放：只顯示字幕並按估計時間繼續，比賽不會卡住。
- 「瀏覽器語音後備」只會使用電腦內置的 **zh-HK／yue** 語音；如電腦沒有粵語語音就不發聲，**絕不會改用普通話**。
