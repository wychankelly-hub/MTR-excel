# 角色圖片清單及規格

遊戲目前使用系統內建的原創 SVG 插圖。你可以隨時在 **教師控制台 →「角色圖片」** 上載插圖（存放在雲端資料庫，所有裝置即時使用）。未上載的表情會自動用該角色的「平常」圖片；完全沒有圖片的角色繼續使用內建插圖，所以可以逐步提供。

## 需要的圖片
| 角色 | 身份／性格 | 必需 | 建議 |
|-|-|-|-|
| **陳定**（chanding） | 冷靜的實習生，玩家代表；整齊短髮、眼鏡、深藍色站務背心 | 平常、說話 | 眨眼、開心、擔心、驚訝、思考 |
| **火箭仔**（rocket） | 速度快但常寫錯公式；刺蝟頭、橙色外套、自信 | 平常、說話 | 眨眼、開心、擔心、驚訝、思考 |
| **肥站長**（fatmaster） | 經常慌張的站長；圓臉、站長帽、八字鬍、紅領帶 | 平常、說話 | 眨眼、開心、擔心（慌張）、驚訝、思考 |
| **八仔**（bat） | 友善的提示小助手；原創吉祥物（現時為紫色八爪魚＋小帽） | 平常、說話 | 眨眼、開心、擔心、驚訝、思考 |
| 喂喂叔（uncle） | 第 2 關客串乘客，拿着電話 | 平常、說話 | — |
| 乘客甲（passenger） | 第 3 關客串乘客 | 平常、說話 | — |

最少：4 位主角 × 2 張（平常、說話）＝ **8 張**。
完整：4 位主角 × 7 張 ＋ 2 位客串 × 2 張 ＝ **32 張**。

## 七種表情
| 檔案（上載位置） | 用途 |
|-|-|
| 平常 neutral | 站立、聆聽（必需） |
| 說話 talk | 與「平常」完全相同，只是**嘴巴張開**；說話時與「平常」交替顯示，按配音音量做口型 |
| 眨眼 blink | 與「平常」完全相同，只是**眼睛閉上**；每數秒自動眨眼一次 |
| 開心 happy | 學生答對、完成關卡、最終揭曉 |
| 擔心 worried | 學生答錯、網絡問題 |
| 驚訝 surprised | 劇情轉折 |
| 思考 think | 部分答對時的提示 |

## 技術規格
- **格式**：PNG 或 WebP，**透明背景**；每張不超過 4 MB（建議 300 KB 以下）。
- **尺寸**：800 × 960 像素（寬 : 高 = 5 : 6）。
- **構圖**：上半身、正面或四分之三側面；頭頂留約 5% 空位；身體底部貼齊畫布底邊（角色會站在月台上）。
- **一致性**：同一角色所有表情的位置、大小、身體姿勢完全相同，只改變臉部（或少量手勢），切換時才不會跳動。
- **風格**：四位主角風格一致；線條清晰、色彩鮮明，在投影幕遠距離亦易辨認。
- **版權**：必須是原創或已取得使用授權；不要使用港鐵或任何機構的標誌、制服徽章或吉祥物。

## 上載方法
教師控制台 →「角色圖片」→ 在對應的格按「上載」→ 選擇檔案。上載後投影畫面、學生畫面及老師畫面會在重新整理後使用新圖片。可隨時「更換」或「刪除」（刪除後回復內建插圖）。

如你把圖片直接交給 Claude，請按 `角色_表情.png` 命名，例如 `chanding_neutral.png`、`chanding_talk.png`、`fatmaster_worried.png`。
